# Charity Ayo Foundation – Widows' Empowerment & Family Support Programme

A modern, high-converting, mobile-responsive landing page created for **Charity Ayo Foundation** to promote its **Widows' Empowerment & Family Support Programme** in Lagos State, Nigeria.

Built with **React**, **Tailwind CSS**, and **Lucide Icons**, following the visual identity, color scheme, typography, and photograph from the official programme flyer.

---

## 🎨 Visual Identity & Branding

- **Primary Colour**: Deep Navy Blue (`#05052F` / `#03031D`)
- **Secondary Colour**: Golden Yellow (`#FFB719`)
- **Accent Colour**: Crimson Red (`#D90000`)
- **Backgrounds**: Pure White (`#FFFFFF`) & Crisp Light Grey (`#F8FAFC`)
- **Typography**: Condensed bold typography (`Oswald` / `Montserrat`) for high-impact headlines paired with `Plus Jakarta Sans` for readable body text.
- **Imagery**: Preserves the original photograph of the dignified woman in traditional black lace gele, necklace, and attire extracted directly from the master design assets with a transparent cutout and responsive optimization.

---

## 🚀 Sections Overview

1. **Header & Navigation**: Sticky navbar with Foundation logo, smooth-scroll links, quick WhatsApp button, and mobile slide-out drawer.
2. **Hero Section**:
   - Official foundation badge & logo
   - Condensed bold heading: `WIDOWS' EMPOWERMENT` & `& FAMILY SUPPORT`
   - Primary button: `APPLY FOR SUPPORT` (links directly to Google Form)
   - Secondary button: `WHATSAPP ENQUIRIES` (opens pre-filled WhatsApp chat)
   - High-resolution photograph of the woman in lace gele
   - Key highlights strip (100% Free, Lagos State Widows, Transparent Process)
3. **Key Dates Strip**: High-contrast milestone badges mirroring the flyer (`12th – 30th Nov 2026` Application Period & `12th Dec 2026` Presentation of Grants).
4. **About the Programme**: Official foundation mission, objectives, and impact pillars (Financial Dignity, Independence, Educational Continuity, Transparent Selection).
5. **Available Support**:
   - *Financial Grant for Startups*
   - *Educational Support*
   - *Business Grant for Expansion*
   - Each with dedicated icons, criteria highlights, and direct application CTAs.
6. **Application Period**: Detailed visual breakdown of the application window and the grant presentation event.
7. **Who Can Apply? (Eligibility)**: Clean 4-point checklist format with guidance on preparing the one-page proposal and documents.
8. **Application Call to Action**: Prominent high-visibility `APPLY NOW` section linking to Google Form.
9. **WhatsApp Enquiries**: Direct WhatsApp integration with pre-filled message, direct telephone dialer (`08033945161`), and options for prospective donors/sponsors/volunteers.
10. **Interactive FAQs**: Addresses common questions from applicants regarding eligibility, fees (100% free), assistance, and disbarment.
11. **Footer**: Foundation tagline, quick navigation, phone, WhatsApp icon, and copyright.
12. **Mobile Sticky Action Bar**: Bottom bar on mobile screens with instant Apply & WhatsApp access.

## 💻 Tech Stack & Commands

### Prerequisites
- Node.js 18+ (tested on Node v24)
- npm

### Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
```
The output will be generated in `dist/`.

### Preview Build Locally
```bash
npm run preview
```
